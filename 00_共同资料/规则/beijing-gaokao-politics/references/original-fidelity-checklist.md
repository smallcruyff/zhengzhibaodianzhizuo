# 北京高考政治逐题原题保真验收协议

`policy_revision: 15`
`last_updated: 2026-09-13`
`scope: 所有进入宝典、Excel、附录与局部题块的原题内容`

## 原则

题目、材料、设问、选项、题号、分值、图片、表格、图注和单位属于客观存在的题面，只做准确完整搬运。纠错以原卷为准，不能为顺口、缩短或适配知识节点而改写。

必修二另执行 `REQ-BX2-20260820-001` 的专属强化：题面材料必须逐项完整，不得只留摘要、提炼句或改写；在文字一致之外，还要保留原卷的题号、小问、材料层级、段落顺序、图表、注释、设问及必要版面关系，使学生获得接近直接阅读试卷的观感。用户随后删除了本册【材料原文】【设问】可见标签，该删除不改变原题完整性。该专属要求不授权把无关整页、相邻题或原页脚一并截入。图注相对字高、图表版心占比和左右/上下关系按版式协议单独对照，完整无裁切不等于比例正确。

选必二另执行 `REQ-XB2-20260823-002` 的专属强化：主观题统一用【题目】承载完整原题，不再设置【材料触发点】或独立【设问】。所有既有概括句逐题回原卷替换为题号、小问、分值、完整材料、原设问、配图、表格、图注、注释和独立作答所需版面；原卷有图表时不得改写为文字摘要或仿制简表。选择题设问在正文、A1、A2删除空括号，其余题面保真要求不变。

必修三另执行 `REQ-BX3-20260823-002` 的专属呈现强化：真题文字、题号、小问、分值、材料、设问、表头、行列、单位、图注和注释必须与原卷逐项一致；能无损核对时优先转为 Word 原生文字和表格，以提高连续阅读与打印清晰度。卡片、复杂图示或难以无损重建的特殊版式使用原卷裁图，并尽可能放大到正文可用宽度；100% 页面查看仍不可读即不合格。原生重建不得以摘要、改写或仿制缺项替代原题。

选必一另执行 `REQ-XB1-20260827-002` 的专属视觉强化：全部【题目】必须逐题回原卷核对题号、小问、分值、材料层级、自然段、选项、表格、图片、图注、注释和原设问，并在 Word 中保留独立作答所需的必要版面关系。原卷同一自然段的物理折行应合并，由 Word 版心自然换行；材料一二三、引用段、列表、表格行、图注和注释分别保持原有层级。禁止把 PDF 每行行尾、OCR 断行、词内断行或编写者为了塞版而添加的软换行当成原题结构。验收以学生获得接近直接阅读试卷的观感为准，单纯文字哈希相同、可渲染或无裁切不能证明视觉保真通过。

哲学宝典另执行 `REQ-PHI-20260827-002` 的专属段落强化：全部【材料原文】逐题回原卷核准自然段、材料层级、引文、列表、图表、注释和必要版面关系。同一自然段内的PDF物理行尾、OCR折行和人工软换行必须合并，由Word版心自然换行；真实自然段仍分别使用独立Word段落。验收须比较原卷页面与最终渲染页面的阅读节奏，文字内容相同、文件可渲染或页面无裁切均不能单独证明排版通过。

题块删除、移动或重分节点不得吞掉相邻的 Heading 1／Heading 2、目录书签、分节标题或附录入口。生成器须把结构标题列为删除白名单外对象；交付前核对顶层标题完整序列、目录目标书签基数，并在最终 PDF 全文扫描 `Error: Reference source not found`／“未找到引用源”等失效字段。原题裁图只允许包含目标题必需区域；一张图在多个落位复用时，发现多截下一题、设问、页眉页脚或像素残片，必须修复源裁图并回归全部重复位置，不能只修用户指出的一页。最终增量修订须用同渲染器做全页差异清单，逐页复核全部变化页，并证明其余页面不受影响。

每个题块同时执行**最小充分原题**：保留目标小问独立作答所必需的共同材料、专属材料、图表、定义、注释、数据、实验步骤和目标设问；删除无关兄弟小问、后续材料和答案页污染。压缩后无法仅凭当前题块作答即不合格。

## 逐题验收表

每个实际使用的正文呈现单元都建立一条验收记录。呈现类型按当前宝典专属记录和有效母本的实际结构登记：已确认三层模型的书包括完整主位、节点索引卡和局部题块，选必二 v14.1 包括每个有效节点落位，已确认保留正文例外专区的书登记实际例外题块，必修三 v5.7-R 系列沿其既有题块形态登记。本协议只验收实际对象，不构成新增题块、索引卡或例外专区的义务：

| 验收项 | 必查内容 | 合格标准 |
|---|---|---|
| 来源定位 | 原卷文件名、页码、题号、小问 | 能回到唯一原件 |
| 题号与分值 | 大题号、小问号、括号形式、总分 | 与原卷逐字符一致 |
| 材料 | 标题、段落、引文、省略号、脚注、来源 | 内容完整，顺序不变，无擅自删改 |
| 必修二试卷观感 | 原卷题号、小问、材料层级、段落、图表、注释、设问与必要版面关系 | 逐项与原卷一致；不使用摘要、提炼句或改写；仅凭当前题块即可获得接近直接读卷的阅读体验 |
| 必修二材料段落与换行 | 原卷自然段、材料一二三、图表与数据行、注释；Word 段落、软换行和裸文本换行 | 自然段边界与原卷一致；同段物理折行已合并；无词内断行、年份或单位拆行、无依据缩进；不得在单个 `w:t` 中用裸换行模拟多个自然段 |
| 哲学材料原文段落与换行 | 原卷自然段、材料层级、引文、列表、图表、注释；Word段落、软换行和物理行尾 | 逐题回原卷核准；同一自然段物理折行已合并且由版心自然换行；真实段落分开；页面节奏接近原卷，无任意断行、首行缩进漂移或孤立短行 |
| 选必一题面视觉与换行 | 原卷自然段、材料层级、题号小问、选项、图表、注释；Word 段落、软换行、制表位和题块版面 | 逐项回原卷核准；同一自然段无人工软换行或 PDF 物理折行，材料层级与视觉关系接近原卷；例题4等用户样例及全书同类任意换行残留为0 |
| 结构标题、目录与重复裁图 | Heading 1／Heading 2完整序列、目录书签与页码、失效字段；裁图边界及同图全部重复落位；最终渲染差异页 | 题块删除未吞结构标题；目录无失效引用且跳转目标存在；裁图不含下一行／邻题／页眉页脚残片；全部重复位置通过；变化页逐页复核、其余页有同渲染器不变证明 |
| 设问 | 知识范围、任务动词、限定语、对象、分值 | 原文完整复现，不做概括改写 |
| 选项与序号 | A/B/C/D、①②③④、组合顺序、标点 | 文字与顺序一致，无乱码或替换 |
| 空括号与编辑标签 | 原卷是否存在 `（）`；“文本信息：”等字样是否属于原题 | 原卷没有就不添加；删除编辑者自加标签，但保留原设问中的“阅读文本信息”等任务文字 |
| 图片 | 边框、图例、坐标轴、刻度、单位、标注、来源；截图范围与无关页眉页脚 | 信息完整、清晰、与题号匹配；只保留题意所需区域，不夹带无关题目、原卷页脚、原页码或大片空白 |
| 表格 | 表题、表头、单位、行列、合并单元格、脚注 | 无缺行缺列，阅读顺序不变 |
| 专名与符号 | 人名、地名、机构、法规、数学和逻辑符号 | 无 OCR 同形字、乱码或全半角误换 |
| 局部题块 | 上下文、限定词、图表依赖、主位跳转 | 独立可读且不改变题意；否则撤回局部展示 |
| 节点索引卡 | 仅适用于当前母本已确认存在索引卡的书；题目唯一标识、小问、E1 槽、分值或关系、主位页码或书签 | 信息与 Excel 一致，跳转到正确完整主位；母本无索引卡时不得由本项补建 |
| 选必二有效节点落位 | 题目唯一标识、当前知识节点、该节点对应 E1 槽、独立作答所需完整原题、四个固定栏目 | 该位置只承载当前节点获 E1 支持的内容；【题目】完整保留原材料、设问、题号、小问、分值和原图表，不因多节点落位改写题意；与 Excel 落位记录一致 |
| 例外题块 | 仅验收当前母本或用户专属确认已经保留的正文例外题块；完整试卷唯一标识、源 ID、题号、小问、例外身份、E3 来源 | 原题逐项保真；知识节点与全部 E1 字段为空；正文标签、Excel 状态和 E3 来源一致；只有后台例外状态时不得据此新增正文专区 |
| 正文映射 | 当前有效母本实际采用的题块类型、选必二 v14.1 有效节点落位、已确认正文例外题块、Excel | 唯一标识、落位类型和位置完全一致；后台字段不得反向规定学生版结构 |

## 验收状态

每项只允许以下状态：

- **未核验**：尚未逐项对照原卷。
- **已核验**：逐项一致。
- **已复原**：发现改写、缺漏或错配，已经恢复原文并二次核验。
- **来源冲突**：不同版本原卷存在差异，尚未确认权威版本。
- **不合格**：仍有缺漏、乱码、错图或无法复核内容。

存在未核验、来源冲突或不合格项时，该题不能通过正文落位门。

## 用户指出一例后的扩展检查

| 用户指出的问题 | 强制扩展范围 |
|---|---|
| 一道设问被改写 | 全书全部设问原文 |
| 一个题号或分值错误 | 同卷全部题号、小问和分值；全书同格式字段 |
| 一个乱码选项 | 全书全部选项序号和特殊符号 |
| 一张错图或漏图 | 全部图片的题号、页码、用途与内容完整性 |
| 一个表格缺项 | 全书所有表格的行列、单位、表头与跨页状态 |
| 一个局部题块截断题意 | 全部局部题块的独立可读性 |
| 一道题缺少必要共同材料、图表或定义 | 全书全部题块的独立可作答性和四边裁切完整性 |
| 一处出现原卷没有的空括号或编辑标签 | 正文、A1、A2 全部题干；同时核验原卷任务指令没有被误删 |
| 一组圈号或 A—D 错位 | 正文、A1、A2 全部圈号悬挂、固定列、续行与换页 |
| 一个例外题块题面或身份错误 | 全部例外题块的原题、完整唯一标识、源 ID、例外类型、E3 来源和空置 E1 字段 |
| 一处材料原文出现词内断行、物理折行或段落塌缩 | 全书全部 `【材料原文】`；逐题回原卷核自然段、材料层级、图表行、注释、Word 段落边界、软换行和裸文本换行 |
| 哲学宝典一处材料原文出现物理折行或试卷观感失真 | 哲学宝典全部 `【材料原文】`；按唯一题键回原卷核自然段、材料层级、引文、列表、图表、注释、软换行、缩进和最终渲染阅读节奏 |
| 选必一一道题出现任意换行或与原卷视觉结构不符 | 选必一全部636个题块的【题目】；按唯一题键去重回原卷核自然段、题号小问、选项、图表、注释、软换行、制表位和必要版面关系 |

排查后在纠错账本记录样例、错误模式、检索范围、命中数、修正数、排除数、Excel 同步状态和正文同步状态。

## 完成判定

1. Excel 中每道纳入题都有保真状态。
2. 所有实际使用的正文呈现单元，包括选必二 v14.1 有效节点落位，达到已核验或已复原；不存在的题块类型不要求补建。
3. 原题复原数按题目唯一标识计数，并可回查具体修正。
4. 图片和表格同时通过内容完整性与页面渲染检查。
5. DOCX、PDF 和 Excel 的题号、小问、分值与唯一标识一致。
