## 本轮适用范围

计数口径保持不变。终审核对全书全部指标；局部修改只更新受影响的题键、映射、公式与汇总，并核对其依赖。可沿用身份匹配且无反例的基线记录，不为改一处文字新建整套工作簿或重算无关历史。用户明确要求的全量盘点仍须全量完成。执行与宪法读取统一见[AGENTS.md](../AGENTS.md)。

## 四套计数口径

| 指标 | 计数单位 | 去重键 | 必须单列的情况 | 禁止混用 |
|---|---|---|---|---|
| **唯一题数** | 一道题或一个具有独立设问或独立分值的小问 | 试卷唯一标识 + 题号 + 小问 | 主观题、选择题及全部互斥主状态 | 不能按知识节点或汇编镜像重复计题 |
| **正式细则槽数** | E1 中一个可独立计分的评分槽 | 题目唯一标识 + 来源槽编号 | 固定槽、任选槽、替代槽、正式角度池或知识池中的可采槽 | 同槽同义表达不能拆成多个槽；等级赋分、分档表、宽泛整体评分表和整体定档表不能计槽 |
| **知识节点归置频次** | 一个评分槽对一个知识节点的有效映射 | 成品链 + 题目唯一标识 + 槽编号 + 节点编号 | 主位落位、交叉索引、跨宝典索引；选必三两册间的跨册关系另记 | 不能用正文复制次数替代 |
| **正文题块数** | 学生版中实际出现的题块 | 文档 + 题块类型 + 题目唯一标识 + 知识节点或例外专区标识 | 当前有效母本真实存在的题块类型；已确认三层结构的完整主位、节点索引卡、局部题块；选必二 v14.1 的有效节点落位；已确认保留的具名例外题块 | 不能当作唯一题数或正式槽数，也不能用统计字段反向创造可见题块 |

### 正式细则槽判定

1. 一个槽代表一次独立计分机会。
2. 同一槽内的同义、替代或任选表达仍计一个槽，并记录内部关系。
3. 两个知识表达只有在 E1 明确可分别计分时才计两个槽。
4. 同题官方分档、等级或整体评价可证明其明示的整题条件，但不自动生成固定评分槽、逐点分值或知识节点。只有宽泛模板、无法配对或没有所需节点依据时仍保留对应未决。完整E1资格与固定槽计数分别按evidence-policy核验，不混为一项。
5. 2024 顺义二模确认例外和 2026 石景山期末常规例外均不计 E1 合格题数和正式细则槽数；两类数量分别统计。
6. 2026 北京高考主观题按第三套具名例外使用官方参考答案时，同样不计 E1 合格题数和正式细则槽数；另记“2026 北京高考确认例外”状态和官方 E3 来源。
7. 必修二 2024 石景山一模第 19 题第（1）问按用户 2026-08-27 题级特批登记，同样不计 E1 合格题数、正式细则槽数和知识节点归置频次；另记“2024 石景山一模 Q19（1）题级确认例外”状态、讲评 PPT 与教师版 E3 来源。

## 唯一标识与去重

### 试卷唯一标识

采用：`年份 | 考试主体或区县 | 考试类型 | 学段与学期 | 试卷名称`。

### 题目唯一标识

采用：`试卷唯一标识 | 题号 | 小问`。同一大题多个小问各有独立设问或分值时，分别登记，同时保留共同大题标识。

### 重复题处理

1. 同一原题被不同汇编重复收录，只保留一个来源主记录，其他文件作为镜像来源。
2. 同材料改编、题号变化或设问变化的题不得机械去重；保留各自题目唯一标识并记录关系。
3. 同题在多个知识节点出现时，唯一题数仍为一，节点归置频次按有效映射分别计算。
4. 选必三思维宝典与推理宝典分别在本册内去重、统计。跨册同一原题在两册各自计一道本册唯一题，并使用共同原题键登记跨册关系；项目汇总若需要全项目去重，另报跨册合并口径，不得用合订版旧口径压缩任一册正文。

## 主状态分区与对账

每个**主观题**唯一标识在任一审计时点必须且只能属于一个评分证据主状态：

1. **E1 纳入**：同题同小问 E1 已核验，并进入本书学生版正常知识体系。
2. **非细则原因排除**：因越界、非本书模块或其他已核验原因不进入正文。重复镜像只在文件层统计，不新增唯一题。
3. **待配对**：原题已识别，尚未定位候选评分材料。
4. **待复核**：已定位 E1 候选，尚未完成同题对应与原件核验。
5. **来源待复核**：旧版有疑似细则线索，原始来源尚未找回。
6. **细则继续检索**：没有可信旧细则线索，当前尚未找到 E1。
7. **证据冲突**：来源、题号、评分结构或版本之间存在未解决冲突。
8. **2024 顺义二模确认例外**：用户逐卷确认该卷没有正式细则，按完整试卷唯一标识与源 ID 锚定，只有 E3。
9. **2026 石景山期末常规例外**：按完整试卷唯一标识与源 ID 锚定，只有 E3。
10. **2026 北京高考确认例外**：按正式题面、官方参考答案和用户 2026-08-22 特批锚定，主观题只有方向性 E3，不拆正式评分结构。
11. **2024 石景山一模 Q19（1）题级确认例外**：只适用于必修二该小问，按题目唯一标识、讲评 PPT、教师版答案和用户 2026-08-27 特批锚定；只有方向性 E3，不拆正式评分结构，也不扩张到同卷其他题目。

主观题建立以下恒等式：

`唯一主观题数 = E1 纳入 + 非细则原因排除 + 待配对 + 待复核 + 来源待复核 + 细则继续检索 + 证据冲突 + 2024 顺义二模确认例外 + 2026 石景山期末常规例外 + 2026 北京高考确认例外 + 2024 石景山一模 Q19（1）题级确认例外`

客观题不适用 E1 细则状态，另建：

`唯一选择题数 = 客观题纳入 + 客观题非模块排除 + 客观题待核验`

- **E1 合格题数**只等于 E1 纳入题数。已经核验但因越界等原因排除的题，不计入本书 E1 合格题数。
- **正式细则槽数**和**正式知识节点归置频次**只从 E1 纳入题计算。未决、排除、三套整卷 E3-only 例外及该题级 E3-only 例外均为零槽、零正式归置频次。
- 重复镜像、损坏文件和资料读取状态属于文件层统计，不能进入题目主状态恒等式制造重复题数。
- 宣称终审完成时，待配对、待复核、来源待复核、细则继续检索和证据冲突必须全部为零，恒等式仍须成立。
- 客观题待核验数量也必须为零，其原题、答案与 A1/A2 闭环按样式和保真协议验收。

## 正文落位模型、节点可见与例外题块

完整主位、节点索引卡和局部题块首先是去重、映射与计数术语。只有当前宝典专属记录或有效母本已经确认采用三层呈现时，学生正文才沿用以下外观；本协议本身不授权把既有宝典批量迁移到三层模板，也不授权新增标题、卡片或导航语言。具有 E1 的同一题在已确认三层模型中按下表处理：

| 层级 | 内容 | 适用位置 | 计数方式 |
|---|---|---|---|
| **完整主位** | 完整材料、原设问、图片表格、细则说明、答案落点与分析 | 最能承载整题主要考法的唯一节点 | 唯一题数一次；正文完整主位一次 |
| **节点索引卡** | 题目唯一标识、该节点对应的 E1 槽、分值或关系、主位页码或书签 | 其他获得正式细则支持的节点 | 增加节点归置频次和索引卡数，不增加唯一题数 |
| **局部题块** | 与当前节点直接相关的原题局部、对应槽及跳转信息 | 只靠索引不足以教学，且局部可保持题意完整时 | 增加局部题块数，不增加唯一题数 |

局部题块不得截断理解所需的材料、图例、限定词或设问条件。不能证明局部独立可读时，只用节点索引卡并跳转完整主位。

每个 E1 支持的知识节点须在 Excel 中完成可追溯映射；正文可见方式服从当前宝典已经确认的落位模型。已确认三层结构的书用完整主位、节点索引卡或合格局部题块闭环，选必二 v14.1 用有效节点落位闭环，必修三 v5.7-R 系列沿其既有题块形态闭环。节点整层无例题或题量异常偏低时，必须回查全题源和映射过程；回查只扩大检查范围，不能自动新增可见题块。

### 选必二 v14.1 落位例外

1. 选必二在用户明确批准改结构前，沿用 v14.1 的复合题多知识节点有效落位，不强制套用完整主位、节点索引卡、局部题块三层呈现。
2. 同一题在正式答案或细则真实支持多个知识节点时，可在相关节点分别出现；每个位置只保留该节点对应的材料触发、法理依据、答案落点和细则说明。
3. 唯一题数仍按题目唯一标识只计一次；正式细则槽按 E1 真实结构计数；槽到节点的映射计知识节点归置频次；正文中每个合格节点位置另计一次**有效节点落位**。
4. v14.1 的 122 个独立法律主观任务、516 次有效主观题落位和 117 道选择题 A1/A2 训练是结构回归基线，不是全题源终审目标值。后续增减必须逐题解释，不能为满足数字保留误收或伪细则。

### 必修三 v5.7-R 系列微修冻结

1. `ART-BX3-V5.7-BASE-20260815` 及其 R1-R5 受控链的既有题块外观、四栏目布局、目录层级、导航语言、附录形态、题序和阅读节奏构成当前回归基线。三层呈现只可作后台映射术语，不形成新增正文义务。
2. 正文题块数按当前认可 v5.7-R 候选实际存在的类型统计；节点索引卡数为零或某类题块不存在均为合法统计结果，不得为了让字段非零而制造题块。
3. 漏归题只克隆相邻同类型题块并在本节点既有顺序内局部插入；误归题只删除有证据命中的题块。未经用户另行授权，不执行全书重排或连续重做全部编号。
4. 三类 E3-only 例外保留后台状态。v5.7-R 链没有用户确认的新书末例外专区时，不得据此新增一级标题、正文专区或重排附录。

### 选必三跨册关系

1. 思维宝典与推理宝典是两份独立成品，各自判断该题是否符合本册知识边界；符合时在本册设置正常题块，不强迫其中一册只放索引。
2. 两册使用共同原题键和 `cross_book_relation` 记录同源关系。每册唯一题数、正式槽、节点归置和正文题块分别报告；项目汇总可另报去重后的共同原题数。
3. 同一册内仍只设一处完整主位或按本册既有落位模型处理，不得因跨册关系在本册重复全文、重复主位或重复计数。
4. 旧合订版“第一部分／第二部分／跨部分”字段保留为历史映射，不再规定两份独立成品的正文结构或计数。

### E3-only 例外题块

| 类型 | 正文位置 | 内容 | 计数与空字段 |
|---|---|---|---|
| **2026 石景山期末常规例外题块** | 仅在本书专属记录或有效母本已确认保留的例外专区 | 完整原题、完整唯一标识与源 ID、例外证据说明、明确标注的 E3 参考答案 | 唯一题数按主状态计一次；正文确有该题块时另计一次；知识节点、E1 来源、评分槽、归置频次、主位、索引卡、局部题块均留空 |
| **2024 顺义二模确认例外题块** | 同上；未确认正文专区时只保留后台状态 | 完整原题、完整唯一标识与源 ID、用户逐卷确认日期、明确标注的 E3 参考答案 | 唯一题数按主状态计一次；正文确有该题块时另计一次；知识节点、E1 来源、评分槽、归置频次、主位、索引卡、局部题块均留空 |
| **2026 北京高考确认例外** | 服从本书专属记录与有效母本；不得据此新建书末例外专区 | 完整原题与官方参考答案的方向性 E3，明确标记“2026 北京高考确认例外” | 唯一题数按例外主状态计一次；E1 合格题数、评分槽和正式归置频次为零 |
| **2024 石景山一模 Q19（1）题级确认例外** | 服从必修二专属记录与当前候选；不得扩张到同卷其他题目或据此新建专区 | 完整原题、讲评 PPT 与教师版方向性 E3，明确标记题级特批 | 唯一题数按例外主状态计一次；E1 合格题数、评分槽、知识节点和正式归置频次为零 |

三套整卷例外和这一道题级例外都不能把 E3 内容拆成正式评分槽或正式归置频次。既有学生题面与参考答案呈现服从本书专属记录，不得据此新增例外专区或重建正文结构。

## 受控排序

以下排序键只在用户明确授权全书重排、新建结构，或确定新增题在当前节点内的局部插入位置时使用。对既有有效母本，未获重排授权时不得移动未命中题块、重做全书编号或改变附录起页。获授权移动的正文题块、索引或选必二 v14.1 有效节点落位，与目录编号采用同一排序结果，不得只改编号：

1. **题型**：主观题优先于客观题。
2. **来源层级**：北京高考真题优先于区县模拟题。
3. **区县层级**：海淀、西城、东城、朝阳、丰台、郊区。
4. **考试类型**：一模、二模、期末、期中。
5. **年份**：从新到旧。
6. **同卷顺序**：题号、小问、选项原顺序。

**郊区是一个共同层级，郊区内部不预设固定优先级。**用户在具体任务中给出顺序时按该顺序；未给出时沿题源清单的稳定原始顺序，不能自行写死完整区县序列。

北京高考真题没有区县排序。其他特殊考试类型在审计表标记后，按用户确认或题源清单稳定顺序放置。

本书已经确认保留“细则例外题”专区时，专区放在正常知识体系之后，内部继续执行来源层级、区县层级、考试类型、年份和同卷题号顺序。未确认专区时不得由本条创建。

## 节点题量版本回归

在本轮影响范围内，候选版与本轮实际working_head前驱比较以下指标；全书终审覆盖全部指标，rollback_base另作结构参照：

- 唯一主观题数、唯一选择题数。
- E1 合格题数、正式细则槽数、归置频次。
- 每个一级标题和知识节点的唯一题数、槽数、归置频次。
- 按当前有效母本真实存在的题块类型统计；已确认三层结构的书统计完整主位、索引卡、局部题块，选必二 v14.1 统计有效节点落位，必修三 v5.7-R 系列统计其既有题块类型且零索引卡合法。
- 2024 顺义二模确认例外题块与 2026 石景山期末常规例外题块数。
- 非细则原因排除题、来源待复核、细则继续检索、2024 顺义二模确认例外和 2026 石景山期末常规例外数。
- 2026 北京高考确认例外题数。
- 2024 石景山一模 Q19（1）题级确认例外数。

任何节点下降都生成差异表，列出消失的题目唯一标识、槽编号和正文题块。只有重复合并、证据排除、归类纠错、题源撤回或用户确认的结构调整可以解释下降，并须同步到纠错账本。

已知历史校验信号只用于触发复查，不能替代全量统计：

- 选必一和平与发展曾从十余题异常回退到一两题。
- 选必二法律主观题应达到百题量级、归置频次应达到数百量级；低于该量级先判定为漏扫风险。
- 必修三党基等节点题量异常偏少时须回查全题源。

## Excel 闭环

终审 Excel 至少包含：

1. 试卷和题目唯一标识。
2. 年份、区县、考试类型、题型、题号、小问和总分。
3. E1 来源、页码或图号、评分槽编号、原意、逐点分值、替代或任选关系、真实限制。
4. 一级标题、知识节点、成品链、正文实际落位类型与位置、例外状态、跨模块、跨宝典或选必三跨册标记。已确认三层结构的书细分完整主位、索引卡、局部题块；选必二 v14.1 细分有效节点落位及其对应 E1 槽；必修三 v5.7-R 系列记录其既有题块形态。字段不得反向规定正文结构。
5. 主观题须从 E1 纳入、非细则原因排除、待配对、待复核、来源待复核、细则继续检索、证据冲突、2024 顺义二模确认例外、2026 石景山期末常规例外、2026 北京高考确认例外、2024 石景山一模 Q19（1）题级确认例外中选择一个主状态并记录理由。客观题另记客观题纳入、非模块排除或待核验。
6. 正文动作、执行位置、执行前后状态和复核人或复核轮次。
7. 原题保真、证据、落位、视觉和学生通读状态。

闭环必须同时满足：

- Excel 的每项正文动作都在 DOCX 中逐条验证。
- DOCX 中当前有效母本实际采用的每个题块、节点索引或有效节点落位都能回查 Excel 记录。
- DOCX 实际存在的每个例外题块都能回查完整试卷唯一标识、源 ID、例外类型和 E3 来源，且知识节点与 E1 字段为空；后台存在例外状态不等于正文必须存在例外题块。
- 四套计数可由同一明细表重新计算，汇总数字与正文一致。
- 主状态分区恒等式逐项成立；排除题、未决题和例外题没有混入 E1 合格题数、正式槽数或归置频次。
- 排除记录保留在表内，不能通过删除行制造覆盖率。

## 量化终审报告

声称终审完成时至少报告：

| 指标 | 口径 |
|---|---|
| 总试卷数 | 题源清单中属于本书审计范围的唯一试卷 |
| E1 完整配对试卷数 | 至少含一道需要 E1 的本书主观题，且该卷全部需要 E1 的本书主观题均已完成同题同小问 E1 配对；两类例外不冒充 E1 |
| 证据闭环试卷数 | 该卷全部本书主观题已进入 E1 纳入、非细则原因排除、三套整卷确认例外或 2024 石景山一模 Q19（1）题级确认例外之一，且客观题待核验为零 |
| 唯一主观题数 | 按题目唯一标识去重 |
| 唯一选择题数 | 按原题的题目唯一标识去重；不与题肢项数混用 |
| A1/A2 题肢项数 | 按题目唯一标识加题肢编号计数；A1、A2 与来源映射项数必须相等，同一道选择题可对应多个题肢项 |
| 客观题待核验数 | 原题、官方答案或 A1/A2 身份尚未核验的选择题；宣称终审完成时必须为 0 |
| E1 合格题数 | 只统计 E1 纳入题；排除题、未决题和两类例外均不计入 |
| 正式细则槽数 | 只统计 E1 纳入题的真实评分结构 |
| 知识节点归置频次 | 只统计 E1 纳入题的槽到节点有效映射 |
| 正文例外题块数 | 2024 顺义二模确认例外题块与 2026 石景山期末常规例外题块分别统计，不产生节点归置频次 |
| 排除数 | 仅统计越界、非本书模块或其他逐题非细则原因；不得把暂未找到细则或重复镜像作为题目排除 |
| 重复镜像资料数 | 只在资料层按文件或来源镜像统计，不新增唯一题，也不进入主状态恒等式 |
| 待配对数 | 逐题列明；宣称终审完成时必须为 0 |
| 待复核数 | 逐题列明；宣称终审完成时必须为 0 |
| 来源待复核数 | 旧版记录过细则但本轮尚未重新找到来源的题；宣称终审完成时必须为 0 |
| 细则继续检索数 | 逐题列明；宣称终审完成时必须为 0 |
| 证据冲突数 | 逐题列明冲突来源；宣称终审完成时必须为 0 |
| 2024 顺义二模确认例外数 | 只统计完整试卷唯一标识与源 ID 已核准的顺义二模题目，并列用户逐卷确认日期 |
| 2026 石景山期末常规例外数 | 审计范围实际包含并保留正文时按题目唯一标识统计，单独列明题源 |
| 2026 北京高考确认例外数 | 按题目唯一标识统计；列明正式题面、官方参考答案来源和用户 2026-08-22 特批 |
| 2024 石景山一模 Q19（1）题级确认例外数 | 只统计必修二该小问；列明讲评 PPT、教师版答案和用户 2026-08-27 特批，E1 槽与正式频次均为零 |
| 关键资料未读取数 | 只统计会影响题源或证据完整性的资料；宣称终审完成时必须为 0 |
| 损坏无替代资料数 | 已验证镜像完整替代者另列已解决，不计入本项；宣称终审完成时必须为 0 |
| 漏归补入数 | Excel 与正文同步完成的新增映射 |
| 误归删除数 | 有具体 E1 反证或边界依据 |

| 逐页渲染页数 | PDF 与 PNG 页数应一致 |
| 目录跳转测试 | 测试总数、通过数、失败数 |
| 未完成事项 | 必须逐项披露；宣称终审完成时应为零 |

终审时还须报告主状态分区各项计数并展示恒等式左右相等；证据闭环试卷数必须等于属于本书审计范围的总试卷数。工作耗时、文件页数和主观感受不能代替上述指标。
