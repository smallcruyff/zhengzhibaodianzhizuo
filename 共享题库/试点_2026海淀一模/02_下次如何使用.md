# 下一个任务怎样复用本卷

入口：本目录 `data/index.json` 或 `scripts/bank.py`。不要为这卷重新扫描原PDF，也不要把整个bank.json或浏览页源码读入模型。

推荐在新任务首次使用时核对原件是否仍与题库对应：

```bash
python3 scripts/bank.py verify
```

按册查候选、按题取完整材料：

```bash
python3 scripts/bank.py list --module 必修三 --kind subjective
python3 scripts/bank.py get Q19
python3 scripts/bank.py get Q21
```

这些命令从本目录运行；实际可用Python为 `/Users/wanglifei/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`。`get`只读题包和小型索引/校验清单，不读取整套PDF、不OCR。`verify`核对全部已登记资产与两个原PDF指纹。发现原件更新应重新审查受影响题级材料，不能继续冒称旧题包与新原件一致。

主代理阅读取用包、按需打开对应图和评分原图，完成教材准入和教学写作。原题和E1原文保持冻结，E2教学解释写在书稿层。把定稿题块交给目标宝典自己的插入、计数与导航更新流程；本题库不写Word，也不自动更新任何已收口书稿。

`data/bank.json`是权威结构数据；`packets/`是由它生成的按题文本；`data/claims.json`存题肢独立归属，`assets/`存原页、原尺寸嵌入图和题块裁图。`review/`保留转录、主代理核验和测试依据。不要直接改派生Markdown来掩盖上游原文问题，修复应回到受影响结构记录，并重新生成、核对。
