# 从已认可成果继续制作下一本

`workflow_revision: 1-20260913`
`basis: 必修二全程复盘；本文件是主代理归纳的执行方法，不新增教材框架或证据例外`

新册开工、跨任务接续、大批增补或重复返工时读本文件；普通改字不重新加载整份复盘。具体证据、样式和计数分别引用既有协议，不重复建立一套标准。

## 先明确本册合同，再批量制作

在本册同一份状态中简记：实际工作头与SHA、认可框架及栏目、题源范围、当前样式依据、用户手工部分、本批交付及下一动作。信息从当前文件和已确认记录取得；只有无法核实且会改变结果的缺口才问用户。旧快照里的“正在写”“只能补证”“未终审”等属于当时任务状态，不是阻止当前授权续作的永久限制。

必修二的54321、是如何/应如何、经济链条和第二部分编号属于本册；必修三继续其《政治与法治》框架与【题目】【为什么能想到】【答案落点】【细则说明】。跨册继承的是正式细则反向归类、完整原题、简洁学生语言和统一视觉角色，不是复制经济目录。具体书名、文件和当前状态以对应活动入口核实；“其余七本”不等于新建七个空工程或同时开七条任务。

已有认可样稿时直接提取可复用角色，先用少量代表题在本地验证后推广，不再次等用户批准。新结构或新视觉方向确实需要选择时，先完成包含真实题图、教学和细则的可审样稿再询问。样稿本身必须达标；“只是小样”不豁免图像和排版质量。验证至少涵盖本批实际存在的普通主观题、组合选择题和复杂图表，不能只用最简单的一段文字验证全书模板。

## 一份题源记录支撑不同落位

先从原卷逆向排查，再用同卷同题同小问正式细则确定本册角度。建立或复用已有题键、原题自然段/图表、答案、完整评分条件及核验记录。正文多节点落位允许沿本册认可结构存在，各位置教学围绕当前标题；不为去重强制单主位或索引卡。唯一题数、实际题块数、正式评分槽/节点频次、题肢项数分别统计。

主代理核定题源、教材归属、考法和教学；不能把整卷或整题“已收入”当作全部小问、全部题肢、全部知识节点都准入。主观题看正式角度，单练逐条看判断所需知识；[增量补题协议](incremental-question-intake.md)给出正反例和清单检查工具。2023题包只有答案、没有正式细则时只处理选择题；某一题缺细则不拖住同卷其他已闭合题，也不能据此声称整卷没有细则。

题目数据必须区分原题自然段、小标题、图表、图注和设问，不能把连续提取文本直接当作可排版正文。新增题的分类与教学一次核定后合批写入。字体、段落、题号、图表关系和源题身份随题块一起保留；同题重复落位同步纠错。原题、A1练习和A2答案从相同条目身份维护，正文原题保留所有选项，A1/A2仅包含已准入题肢。

## 在最小层级修错

出现反例时，先判明是内容判断、原件转录、字符格式、段落属性、表格/图片几何、分页还是软件显示造成，再修改这一层及真实依赖。已有布尔标记不能证明教材判断正确；已有“视觉通过”记录不能否定用户截图中的缺陷。重复同一症状时更换诊断依据，不再用同一个全段格式覆盖或整题锁段方案碰运气。

复制题块以语义角色继承：标签和正文分别处理，不能把一个标点的字宽、深蓝或加粗扩散到整段。图片固定行高、过大的图注、跨页定义图、表头悬空、软回车拉伸短行分别处理，见[版式协议](style-spec.md)。原题内容不因美化改写；低清图先找同卷原生/清晰电子版，必要复原也必须有原图依据、逐项核对，不把生成结果当来源。

长题自然跨页，短题和必要阅读单元保持连接。只绑定标题与必要首段、表头与首行、材料小标题与后文；不把整道题、全部答案或几百段连续keep-with-next。不同软件重新分页时，先定位用户使用环境及文件身份；用户已接受的目标环境不再扩成所有阅读器都像素一致的额外任务。

## 合批、增量和检查

来源按SHA缓存，未变来源不重新解压/OCR；缓存命中不等于内容或教材归属已核验。确定性计数、配对、指纹和关系检查交给脚本，教学判断不交给正则表达式。`source_intake.py`可复用；`book_incremental.py`的题块识别目前适配必修二，其他册先只读检查实际结构并适配，不能对必修三盲跑旧经济书脚本。

## 答题点出现规律的同步归纳（2026-09-22）

用户要求：“这个思考和总结的任务是很重要的，需要你调用最好的模型……这个工作应该在制作宝典的过程中同步进行。”各册逐题制作时，由主代理或用户认可的最强模型同步归纳每个答题点在真题材料中的出现结构：主体是自己做事还是多方合作、多个环节前后衔接还是并列、材料明写还是分散叙述需提炼或完全要补出、设问怎样决定写法、细则怎样给分。据此形成原理性类型分类，写进常见表述并作为考法分组，不按表面话题。归纳结论同时为第二轮专题储备素材；第二轮专题可围绕主体、情境、考法、素养、能力或题型设计，先提案经用户认可再做。书成型后补做时按全书推广执行。

## 结束与跨任务交接

区分“用户接受正文并结束制作”“本轮检查通过”和“全书所有证据技术终审通过”。用户确认结束、将封面前言交自己手工时，记录其接受的实际版本和手工边界，停止自发改正文；历史待核事实仍留后台，不能伪造为新关闭，也不因此强迫用户继续这本。

新任务交接只需：已安装Skill入口、本册真实工作头与配套文件、认可框架、已完成和未决、下一动作。完整历史可链接按需查，不将所有旧日志装进启动上下文；保留原始资料和用户批注。用户手改之后须重新核对当前文件，不能用工程旧副本覆盖。

节省的是重复提取、重复解释要求、错误全局修改、无收益等待与重做成本，不是正式证据、核心教研和真实页面检查。模型档位按用户当前设置；不自动重置额度、不自动启用外部收费流程、不把旧授权当新账号操作授权。

## 用这些真实反例检查方案

| 情形 | 应做的判断 |
|---|---|
| 细则里有正式分档，但用户要两句学生说明 | 保留后台完整证据，只写当前标题正式表述和真实计分关系；不臆拆每点分数 |
| 同道经济题含劳动争议诉讼选项 | 正文保留完整选项；单练按教材归属排除该项，不能让drill=true替代判断 |
| 题肢本身正确却不合题意 | 解析里标“不选”加黑色提示，不编“纠正”把正确句改错；单练不收这类题肢（单练只分正确/错误） |
| 链条题肢某一环推不出（如“广告投送→用户成本下降”） | 判“错误”，红标那一环并写纠正；不因整链“不是本题答案”而标不选 |
| 单练某分类表全是错误项（如“程度与范围”） | 把靠恰当程度措辞成立的正确题肢从其他表挪入对照，只挪表不改字；表内正确/错误总体交替 |
| 原题材料有数据或表述错误 | 正文直接改正并在后台台账登记依据；不在学生版加【编者校注】 |
| 用户要整册付印、分册交出版商 | 交付整册同版Word与PDF，页脚页码全书连续；不自行设计分册 |
| 图文完整但“注”比正文大一倍 | 回原卷对比字高和版心比例，同时检查左右图文关系；不是仅看无裁切 |
| 房山材料三个▲标题变成一大段 | 按原卷恢复自然段与小标题，不照抄PDF物理行，也不删除原卷▲ |
| 修了字体后全书颜色消失或整题加粗 | 检查继承与字符区间，仅恢复误改属性，保留其他有效增量 |
| 题目后半页空白，图却到了下一页 | 查必要阅读单元和连接属性，不把整个长题绑定成不可分页大块 |
| 2023.11高三试卷装在2023目录 | 核原卷届别；学生来源名称按全书统一，日期留后台 |
| 必修三历史R32标Blocked | 核对实际文件和有依据的缺陷；承接已授权范围，不套旧整书停止命令 |
