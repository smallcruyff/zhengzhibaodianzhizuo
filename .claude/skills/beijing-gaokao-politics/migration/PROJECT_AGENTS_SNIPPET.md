# 项目入口引用示例

先核实实际加载路径，再合并以下等价引用。不要用本例覆盖其他项目或组织规则，也不要同时维护两份完整执行条款。

```text
北京高考政治教研任务使用当前安装的 beijing-gaokao-politics Skill。
实质制书每轮必须先由主代理全文读取该Skill的宪法执行副本及示范；触发和事务性豁免以宪法读取门禁为准。
执行、授权、代理、恢复和完成条件统一读取该Skill根目录AGENTS.md，专业要求与当前册状态按SKILL.md路由。
常规技术方法、批次和可恢复修复由主代理自主完成；旧固定型号、逐步开工审批、监视握手与无条件Git完成门停用。
原始证据、已确认书级结构、真实验收、平台与组织权限继续有效。
```

常见布局可引用`.agents/skills/beijing-gaokao-politics/AGENTS.md`，实际路径由宿主核验。本包已由SKILL.md显式引用同目录AGENTS.md；文件存在本身不证明任何宿主已自动加载。
