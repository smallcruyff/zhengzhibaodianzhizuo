# 必修三第51批：本轮变化与审查说明

## 一、本轮变化

1. 专题三换成第二轮主体专题，共八个主体，顺序为党、人大、政府、政协、法院与检察院、基层自治组织、人民与公民、社会主体。每个主体依次写：
   - 主体识别：材料里这个主体的各种称呼，以及容易误认的主体。
   - 基本框架：地位与宗旨；做法按组分上位、下位，一句一行；效果。句子取自正式细则、老师讲义和教材原句。
   - 出场方式：按这个主体在事件中的位置分类，每类配真题。
   - 与其他主体的关系：只收细则确实给这层关系算分或点评的。
   - 串联与上升、易混。
   - 例题：材料、设问、思维链条、答案落点、细则（只留整体给分规则和本主体相关点）、学什么。
   原专题三的“必背”各条已在第一部分常见表述里，“见识”各条改由带细则的例题代替。
2. 第一部分“公民的政治权利”“执法”两节的类型写法，以及5处例题的分析、答案落点、细则说明，知情权、参与权、表达权、监督权改为一串写。

## 二、做过的检查

- Word 与 PDF 同版绑定，PDF 按实际页数登记。
- 目录回填后与 PDF 对照。
- 八个主体专题逐一检查：例题编号连续、正文引用的例题对得上、没有竖杠和浮夸词、没有工程说明。
- 政府专题经用户十轮修改后定型；其余七个主体按同一流程制作：逐题回原件抽细则、归并框架与类型、查漏修正、写例题、对照细则复核。

## 三、没做的检查

- 没做全书逐页复看（按用户“先不用至善至美，我先调内容”）。
- 七个新主体专题没经过政府样稿那样的逐轮人工修改，请重点审内容。
- 材料翻译、概念辨析两个专题仍是小样，没有进书。
