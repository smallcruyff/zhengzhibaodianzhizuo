# 新卷、新细则入书流水线（设计稿，2026-09-24）

## 场景

以后每出一批新卷或新细则（新一年的一模、二模、期中期末、高考），都要做四件事：
1. 登记进题库；
2. 判断每道题该进哪几本书；
3. 写好教学内容插进对应位置；
4. 更新单练、编号、目录，然后发审阅稿。

## 现状：Codex 版技能哪里没脚本化

Codex 写的 `references/incremental-question-intake.md` 规则很全，但落到脚本的只有两处：
- `source_intake.py`：只做文件指纹和文字缓存；
- `book_incremental.py`：只管必修二的题量和编号，已被 `layout_prepare.py` 取代。

下列关键步骤仍靠模型读长文手工做：

| 步骤 | 现在谁做 | 为什么费 token |
|---|---|---|
| 判定届别、识别重复登记 | 模型或人 | 照搬目录名，已出错（见 REQ-PROJ-20260924-COHORT-YEAR） |
| 每题该进哪几本书 | 模型逐册通读 | 每本书各读一遍同一批卷 |
| 插在哪个考法下 | 模型读整本书找位置 | 为了找位置读全书 |
| 连图带表插入整道题、重建书签和图片关系 | 模型现写一次性脚本 | 每批重写，还容易丢图 |
| 题肢逐条准入与判断 | 模型 | 这是必须花的，但缺少切好的输入包 |

## 新流程：九步，模型只在第 4、6、7 步出手

| # | 步骤 | 工具 | 模型？ |
|---|---|---|---|
| 1 | 新文件差分：哪些是新卷、新细则、细则修订 | `source_intake.py`（已有） | 否 |
| 2 | 登记卷身份：按卷首学年或考试日期**推算届别**；按题面指纹比对已有卷，**拦住重复登记** | **新：`exam_register.py`** | 否 |
| 3 | 原件转逐题 MD，跑题库验收门 | `doc2md.py`、`bank_compile.py`（已有；扫描页残余交看图） | 仅看图残余 |
| 4 | **只对新题**做模块归属：切片后交 Opus 判定，一张卷约 1 次调用 | 归属表流水线（今天已建：切片→判定→并入裁定日志） | **是（Opus）** |
| 5 | 每本书的“该收”清单，按规则过滤：选择题照收，主观题须有细则；再给出**插入位置建议** | **新：`placement_suggest.py`**：拿新题的设问和细则角度，与本书各考法下已有例题比相似度，给前 3 个候选考法和相邻样板题块 | 否 |
| 6 | 写教学内容：模型只拿取材包（题面＋正式细则）＋前 3 个候选考法的名称与一道样例，定落位、写各栏目，输出为改动单 | `qpack.py` 取材（已有） | **是（唯一的大头）** |
| 7 | 题肢：逐条判断正误、写纠正、定准入 | `drill_tool.py`（三列表已通；段落式、题卡式正在补） | **是** |
| 8 | 插入整道题：按相邻样板题块复制样式，原题的图、表、材料自然段从原件带入，自动重建书签、图形 ID、媒体关系 | **新：`block_insert.py`**（apply_patch v1 不支持图表，是最大的技术缺口） | 否 |
| 9 | 编号、考法题数、目录 → 渲染 → 体检 → 只看改动页 → 发布 | `layout_prepare`、`render_book`、`batch_health`、`page_delta`、`publish_review`（已有） | 仅看改动页 |

外加一个**总控清单 `intake_run.py`**：对“这批新卷 × 各本书”列出每一步的完成状态，并给出下一条该跑的命令。模型不用自己记进度、翻目录。

## 预计省多少

一张新卷约 20 题。

- 旧做法：每本书各读一遍整卷，再为找插入位置读全书，插入时现写脚本。
- 新做法：
  - 归属判定：约 1 次 Opus 调用；
  - 每本书相关的 3—8 题：每题只读自己的取材包和 3 个候选考法，写教学内容；
  - 其余全部脚本。
- 预计每卷全流程的模型花费，降到旧做法的几分之一。
- 模型花掉的钱，基本都在写教学内容和判题肢上。

## 要新建的工具与顺序

1. `exam_register.py`（小）：届别推算、重复登记拦截。本次查出的三张期中卷错号，就是它要防的。
2. `placement_suggest.py`（中）：考法候选与样板题块。
3. `block_insert.py`（大）：连图带表插入整道题。必须用真实新卷在必修三副本上端到端验收。
4. `intake_run.py`（小）：总控清单。
5. 段落式、题卡式单练重建（`drill_tool` build 补齐）。

每个都按“编写 → 对抗验证 → 按需返修”做，验收一律用真实新卷在非必修三的书上走通。建议 09-26 额度重置后开做。
